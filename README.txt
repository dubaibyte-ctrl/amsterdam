Amsterdam Food Scout — installable offline app

Put this whole folder on any HTTPS static host (for example Netlify Drop, GitHub Pages or Cloudflare Pages).
Open the address once on your phone with internet, then:
  iPhone (Safari): Share → Add to Home Screen
  Android (Chrome): ⋮ → Install app / Add to Home screen
After that first online visit it opens in airplane mode. Progress is stored on the phone (localStorage).
Offline: map shows saved pins only; weather, trends and hours show their last saved time.
